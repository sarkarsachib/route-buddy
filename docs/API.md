# Server API (createServerFn RPC; all require a signed-in bearer unless noted)
Passenger (`passenger.functions.ts`): getMe, createQuote, confirmBooking (idempotency key), listMyBookings, getBookingDetail, cancelBooking, retrySearch, makeOffer, respondOffer, reportIncident, openSupportCase, requestRefund, createShareLink, myNotifications, claimDemoRole (demo only), getSharedTrip (**public**, token → state/labels/driver name only).
Driver (`driver.functions.ts`): getDriverDashboard, setAvailability (verified + not restricted), respondAssignment, advanceBooking (assigned driver only), driverCancel, markNoShow (after grace), collectCash, demoDriverDashboard (ops/admin; `demoAct` only for is_demo drivers).
Ops (`ops.functions.ts`): getOverview, getReconciliation, createSettlement, decideRefund, getIncidents, actOnIncident, updateSupportCase, setDriverVerification, getAdminConfig, publishPricing, grantRole, simulatePayment.
HTTP: `POST /api/public/payments/sandbox-webhook` — header `x-signature` = hex HMAC-SHA256(body, SANDBOX_PAYMENT_WEBHOOK_SECRET). Body `{eventId, paymentReference, status, amountPaise}`. Returns `{outcome: processed|duplicate|unknown_payment|amount_mismatch|already_final}`.
